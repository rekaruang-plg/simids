# SiMIDS V6.1 — Polishing Uji Kader

V6.1 mempertahankan seluruh fungsi dan 10 data dummy V6, dengan fokus mengurangi potensi kebingungan saat uji pengguna.

## Perubahan
- Target sentuh kontrol sekunder minimal 44–48 px.
- Tombol tutup popup 48×48 px.
- Tab filter imunisasi minimal 48 px.
- Tombol aksi kecil minimal 44 px.
- Istilah teknis “kohort” di halaman kerja kader diganti dengan bahasa sehari-hari.
- Pemilih peran diberi label **Mode uji**, bukan “Tampilan”, untuk menegaskan bahwa pergantian Kader/Bidan/Puskesmas hanya untuk simulasi prototype.
- Storage/cache PWA dinaikkan ke V6.1 agar pengujian tidak tertahan cache versi sebelumnya.

## Yang tidak diubah
- Struktur input dan ekspor kohort individu.
- 10 anak dummy dan riwayat imunisasi demo.
- Reminder, click-to-WhatsApp, sweeping, dashboard, laporan, dan validasi Bidan.
